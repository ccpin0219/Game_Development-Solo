# 잿빛 성소 — Ashen Sanctum

고정 던전을 탐험하고 두 열쇠를 모은 뒤, 활로 거대 석조 수호자의 약점을 공략하는 1인칭 Unity 게임입니다.

## 실행

1. Unity Hub에서 이 저장소의 루트 폴더를 프로젝트로 추가합니다.
2. **Unity 6000.3.23f1**로 열고 패키지 설치와 에셋 임포트가 끝날 때까지 기다립니다.
3. `Assets/Scenes/SampleScene.unity`를 열고 Play를 누릅니다.
4. 게임 메뉴에서 **탐험 시작**을 선택합니다.
5. 전투방을 탐험하며 적을 처치하고, 열쇠 근처에서 **E**를 눌러 두 개를 모은 뒤 보스 전당으로 이동합니다.

URP와 Input System을 사용합니다. 패키지에 Git URL로 배포되는 Unity MCP가 포함되어 있으므로 패키지 복원 시 Git과 인터넷 연결이 필요합니다.

## 조작법

| 입력 | 동작 |
| --- | --- |
| WASD | 이동 |
| 마우스 | 시점 조작 |
| + / - (시작 방) | 마우스 감도 1~10단계 조절 및 저장. 오른쪽 연습 과녁으로 확인 |
| Space | 점프 |
| Q | 5초 자동 고속 충전 (강공 0.4초 / 속공 0.12초), 좌클릭 발사, 모드 공용 쿨타임 30초 |
| Shift + WASD | 누르고 있는 이동 방향으로 6m 돌진 (WASD 미입력 시 전방, 쿨타임 15초) |
| 좌클릭 유지 / 놓기 | 활 충전 / 발사 |
| 우클릭 | 충전 취소 |
| Tab | 강공 / 속공 전환 (충전 중 전환하면 충전 취소) |
| E | 가까운 열쇠 획득 / 장치 작동 |
| Esc / 좌클릭 | 커서 해제 및 일시정지 / 복귀 |

## 구현 내용

활은 강공(완충 1.2초, 피해 90, 발사 후 대기 0.35초)과 속공(완충 0.35초, 피해 25, 발사 후 대기 0.12초)을 지원합니다. 좌클릭 유지 후 놓으면 발사하며, 완충 전에 놓으면 피해가 감소합니다. 모드 전환으로 발사 후 대기 시간을 건너뛸 수 없습니다.

- 6개 부위의 약점과 부위 파괴에 따른 공격 봉쇄
- 별도 시작 방 → 3×3 던전 → 보스 전당으로 연결되는 고정 던전. 시작 방 바로 앞의 아래쪽 중앙 방은 적이 없는 안전방
- 나머지 8개 방에 입장하면 출입구가 닫히고 해골 2마리와 전투. 적을 모두 처치하면 출입구 개방
- 매 탐험마다 서로 다른 전투방 2곳에 열쇠 배치. 해당 방을 클리어하면 열쇠가 나타나며, 두 개를 모으면 보스 문 개방. 재도전 시 직전과 다른 방 조합 선택
- 도트 배경과 Neo둥근모 글꼴을 사용하는 시작 화면
- 공격별 준비·타격·회복 동작 및 강화된 수호자 외형
- 망치, 돌 투척, 레이저, 도약, 직선·원형·색상 바닥 공격
- 불덩이를 발사하는 화로와 회복 아이템
- 시작·결과·재도전 화면과 로컬 최고 기록 저장
- 석조 성소 장식, 화로 프리팹, 수호자 갑옷과 부위 파괴 연출

## 폴더 구성

- `Assets/Dungeon`: 전투 스크립트와 에셋
- `Assets/Scenes`: 게임 씬
- `Packages`, `ProjectSettings`: 패키지와 Unity 프로젝트 설정
- `Tools`: 씬 장식 제작에 사용한 Unity Editor 실행 코드. 일반 플레이에는 실행할 필요가 없습니다.

Unity 캐시, IDE 생성 파일, 로컬 캡처와 백업은 버전 관리에서 제외합니다. 에셋의 `.meta` 파일은 GUID 연결을 유지하기 위해 함께 관리합니다.

Neo둥근모 폰트의 배포 라이선스는 `Assets/Dungeon/Resources/Fonts/LICENSE.txt`에 포함되어 있습니다.
